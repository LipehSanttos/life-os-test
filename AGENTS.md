# Diretrizes do Projeto (AGENTS.md)

## 🇧🇷 Idioma Obrigatório para Comentários de Código
- **Comentários de Código:** Todo e qualquer comentário inserido no código-fonte (TypeScript, JavaScript, TSX, JSX, SQL, CSS, Shell, etc.) DEVE ser escrito exclusivamente em **Português (pt-BR)**.
- **Documentação de Funções e Componentes (JSDoc/TSDoc):** Todas as anotações de funções, hooks, componentes, parâmetros e retornos devem estar em Português.
- **Mensagens de Log e Debug Internos:** Mensagens explicativas e avisos nos arquivos devem priorizar o Português.
